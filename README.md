# متتبع برامج المؤشرات ١٤٤٨ — تطبيق (PWA)

تطبيق ويب قابل للتثبيت (ويندوز / أندرويد / آيفون) لمتابعة برامج مؤشرات الخطة التشغيلية
لمدارس الأندلس العالمية – الطائف (بنين). البيانات تُقرأ وتُحفظ مباشرة في ملف Google Sheets «متتبع برامج المؤشرات ١٤٤٨»
عبر Google Apps Script (`API.gs` في مشروع «Tracker API»).

- الدخول: الاسم + رمز PIN (عمود «رمز الدخول للتطبيق» في ورقة «المسؤولون»).
- `config.js`: رابط الـ API ومفتاح التطبيق.
- `sw.js`: تخزين مؤقت لواجهة التطبيق (يفتح فوراً ويعرض آخر بيانات عند انقطاع الإنترنت).

Indicator Programs Tracker 1448 — installable PWA front-end for the Google Sheets tracker.
